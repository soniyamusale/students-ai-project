# AI Learning and Memory Tool

AI Learning and Memory Tool is a smart web-based educational application developed using ReactJS, NodeJS, ExpressJS, and MongoDB.

## Features

• User Login System  
• Upload File Support  
• Voice Input using Microphone  
• Automatic Notes Generation  
• Quiz Generation  
• Flashcards Generation  
• Save Study Materials  
• Speech-to-Text  
• Text-to-Speech  

## Technologies Used

• ReactJS  
• NodeJS  
• ExpressJS  
• MongoDB  
• JavaScript  
• HTML  
• CSS  

## Purpose

The project helps students generate notes, quizzes, and flashcards automatically for effective learning and revision.
